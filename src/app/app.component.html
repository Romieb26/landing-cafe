Sistema Inteligente de Monitoreo del Secado de Café

Plataforma inteligente orientada al sector cafetalero capaz de monitorear variables ambientales en tiempo real, predecir condiciones óptimas de secado y generar recomendaciones mediante Machine Learning e IoT.

Planteamiento del Problema

El proceso de secado del café es una de las etapas más importantes en la producción del grano, ya que influye directamente en la calidad final, el sabor y el valor comercial del producto. Actualmente, muchos productores realizan este proceso de forma manual o empírica, basándose en experiencia y observación visual.

Variabilidad Climática

Los cambios ambientales afectan continuamente las condiciones de secado, dificultando la toma de decisiones en tiempo real.

Pérdida de Calidad

El sobresecado o secado insuficiente genera variaciones en la humedad del grano, desperdicio de producto y pérdidas económicas.

Falta de Automatización

Los productores carecen de herramientas inteligentes que apoyen la toma de decisiones y mantengan estándares constantes.

Justificación

El café representa una actividad económica importante para muchas regiones productoras, especialmente en zonas rurales. Mejorar el proceso de secado puede generar beneficios tanto económicos como productivos.

Este proyecto convierte la propuesta en una solución innovadora alineada con la transformación digital del sector agroindustrial, integrando tecnologías actuales como Machine Learning, IoT, cómputo en el borde y análisis predictivo.

¿Cómo Funcionará el Sistema?

Integración de tecnologías inteligentes aplicadas al monitoreo del café.

Machine Learning

Predecirá el tiempo óptimo de secado, detectará anomalías y estimará la calidad del grano mediante datos históricos.

Aplicación Móvil

Permitirá visualizar datos en tiempo real, recibir alertas inteligentes y monitorear el secado desde cualquier lugar.

Plataforma Web

Para supervisores y administradores: estadísticas, reportes y administración del monitoreo multiusuario.

IoT y Sensores

Sensores ESP32 capturarán temperatura, humedad y condiciones ambientales en tiempo real con Edge Computing.

Objetivo General

Desarrollar un sistema inteligente de monitoreo del secado de café capaz de analizar variables ambientales en tiempo real y predecir condiciones óptimas de secado mediante técnicas de Machine Learning e IoT.

Objetivos Específicos

  • • Capturar datos de temperatura, humedad y tiempo mediante sensores IoT.
  • • Monitorear el estado del proceso de secado en tiempo real.
  • • Implementar modelos de Machine Learning para predecir la calidad y duración del secado.
  • • Generar alertas automáticas ante condiciones críticas.
  • • Visualizar información y reportes mediante una plataforma web multiusuario.
  • • Automatizar recomendaciones para optimizar el proceso de secado.

Alcances y Limitaciones

✅ Alcances

  • • Monitoreo ambiental en tiempo real
  • • Almacenamiento histórico de datos
  • • Predicción del tiempo óptimo de secado
  • • Generación de alertas inteligentes
  • • Visualización de estadísticas y reportes
  • • Roles de usuario: productores, supervisores, técnicos y administradores
  • • Integración con IoT y Edge Computing

⚠️ Limitaciones

  • • La precisión del modelo dependerá de la calidad y cantidad de datos recolectados
  • • Se requerirá conexión entre sensores y sistema central
  • • Factores climáticos extremos pueden afectar la precisión de las predicciones
  • • La implementación inicial estará enfocada en escala piloto
  • • El sistema apoyará la toma de decisiones, no automatizará físicamente el secado
